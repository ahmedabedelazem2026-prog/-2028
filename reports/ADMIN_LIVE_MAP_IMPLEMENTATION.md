## 1. نظرة عامة والهدف التشغيلي
تم تزويد لوحة الإدارة المركزية بخريطة جغرافية تفاعلية مباشرة (`adminSectionLiveMap`) تمنح المشرفين وغرفة العمليات بالعريش رؤية شاملة وفورية لحركة الأسطول والرحلات النشطة.

---

## 2. المكونات والميزات البرمجية
1. **عارض الخريطة المظلم الفاخر (Leaflet Dark Map Viewport):**
   - تم دمج خريطة Leaflet مخصصة بأسلوب Dark Carto المتناسق مع هوية المنصة الفاخرة.
   - المركز الافتراضي: إحداثيات مدينة العريش (`31.1316, 33.8016`).
2. **تتبع مواقع الكباتن اللحظي (Driver GPS Tracking):**
   - الاستماع الفوري لعقدة `driver_locations` وعقدة `drivers` في Firebase RTDB.
   - إظهار علامات الكباتن بألوان مميزة تعكس حالتهم:
     - 🟢 **أخضر:** كابتن متصل ومتاح لاستقبال الرحلات.
     - 🟡 **برتقالي:** كابتن مشغول حالياً برحلة جارية.
     - ⚪ **رمادي:** كابتن غير متصل.
3. **تتبع الرحلات والمسارات النشطة (Active Trip Routes):**
   - رسم خطوط سير الرحلات النشطة الواصلة بين نقطة الانطلاق والوصول (`polyline`).
   - إمكانية النقر على أي رحلة أو كابتن لعرض نافذة منبثقة (Popup) تتضمن: اسم الكابتن، موديل السيارة، رقم اللوحة، رقم الرحلة، الأجرة المحددة، ووقت آخر إشارة GPS.
4. **تصفية الخريطة الحية (Live Filters):**
   - تصفية سريعة لعرض (الكل / المتاحون فقط / المشغولون برحلة / مسارات الرحلات الجارية).
5. **مؤشرات الأداء اللحظية (HUD Stats):**
   - إحصاء فوري لعدد الكباتن المتصلين بنظام الـ GPS.
   - إحصاء الرحلات الجارية.
   - عرض دقيق لزمن آخر إشارة GPS مستلمة بالثواني لمنع اعتبار المواقع القديمة مواقع حية.
