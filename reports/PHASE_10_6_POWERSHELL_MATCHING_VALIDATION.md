# PHASE 10.6 — PowerShell Matching Validation

## 1️⃣ Corrected PowerShell Script
```powershell
$staged = @(git diff --cached --name-only)
$excl = @()
$excl += $staged | Where-Object { $_ -eq '.firebase/hosting..cache' }
$excl += $staged | Where-Object { $_ -eq 'all_files.txt' }
$excl += $staged | Where-Object { $_ -like 'assets/images/WhatsApp Image*' }
$excl += $staged | Where-Object { $_ -like 'assets/images/advertising/WhatsApp Image*' }

# Statistics
Write-Output "TOTAL=$($staged.Count)"
Write-Output "CACHE=$($excl | Where-Object { $_ -eq '.firebase/hosting..cache' }).Count"
Write-Output "ALL=$($excl | Where-Object { $_ -eq 'all_files.txt' }).Count"
Write-Output "MAIN=$($excl | Where-Object { $_ -like 'assets/images/WhatsApp Image*' }).Count"
Write-Output "ADV=$($excl | Where-Object { $_ -like 'assets/images/advertising/WhatsApp Image*' }).Count"
Write-Output "EXCL_TOTAL=$($excl.Count)"
Write-Output "REMAINING=$($staged.Count - $excl.Count)"

# Persist the lists for review
$excl | Out-File -Encoding utf8 -FilePath exclusion_list.txt
$staged | Where-Object { $_ -notin $excl } | Out-File -Encoding utf8 -FilePath remaining_list.txt

# Generate safe removal commands (dry‑run only)
$excl | ForEach-Object { "git rm --cached -- \"$_\"" } | Out-File -Encoding utf8 -FilePath removal_commands.txt
```
