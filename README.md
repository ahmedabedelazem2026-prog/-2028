## 💻 تشغيل المحاكي المحلي (Firebase Emulator Suite)

لاختبار وظائف الخادم أو تطوير الوظائف محلياً دون التأثير على بيئة الإنتاج:

1. **بدء تشغيل المحاكي**:
   ```bash
   firebase emulators:start
   ```
2. **المنافذ المخصصة للمحاكي محلياً**:
   - واجهة تحكم المحاكي (UI): `http://localhost:4000`
   - الاستضافة (Hosting): `http://localhost:5000`
   - قاعدة البيانات الحية (Realtime Database): `localhost:9000`
   - السحابية (Firestore): `localhost:8080`
   - الدوال السحابية (Functions): `localhost:5001`

3. **تشغيل الموقع المحلي البسيط**:
   ```bash
   npm start
   # أو
   npx serve -l 3000 .
   ```

## 📱 الميزات المكتملة فعلياً في المنصة

### 1. واجهة العميل (Customer App):
- اختيار طريقة عرض الجهاز (تلقائي Auto، جوال Mobile، تابلت Tablet، كمبيوتر Desktop) مع حفظ التفضيل.
- تحديد الموقع التلقائي عالي الدقة عبر الـ GPS بالعريش مع إمكانية التحديد اليدوي أو سحب الدبوس.
- البحث السريع والإكمال التلقائي للمعالم والشوارع في العريش.
- شريط فوتوغرافي تفاعلي لأشهر معالم العريش (شاطئ النخيل، جامعة سيناء، مسجد النصر، جامعة العريش، مستشفى العريش).
- حساب المسافة، الوقت التقديري، وتسعير كل فئة سيارة (اقتصادي، كمفورت، VIP، عائلي 7 ركاب).
- تطبيق كوبونات الخصم (`CAPITAL10`, `ARISH2026`, `STUDENT15`).
- رادار البحث المتحرك عن أقرب كابتن.
- كارت السائق المعتمد مع لوحة السيارة المصرية، ورمز أمان الرحلة المكون من 4 أرقام (PIN).
- سجل الرحلات السابقة الكامل مع إمكانية إعادة حجز أي رحلة سابقة بضغطة زر.
- حفظ وتعديل الملف الشخصي والأماكن المفضلة في Firebase.
- تقديم الشكاوى والملاحظات مباشرة إلى قاعدة البيانات.
- مشاركة مسار الرحلة الحية عبر واتساب لتعزيز الأمان.

### 2. تطبيق الكابتن (Driver App):
- تسجيل حساب السائق وحفظ بياناته في عقدة `drivers/{uid}`.
- التحقق من اعتماد السائق: يمنع السائق غير المعتمد من استقبال الرحلات مع ظهور تنبيه واضح.
- زر التبديل بين حالتي (متاح 🟢 / غير متاح 🔴) ومزامنتها لحظياً في Firebase.
- كارت استقبال الطلب الجديد الفوري مع عداد تنازلي 25 ثانية، توضيح السعر، نقطة الانطلاق والوجهة، وملاحظات الراكب، مصحوباً برنين صوتي تنبيهي.
- تحديث حالات المشوار الثلاثة:
  1. وصول السائق لنقطة الالتقاء (`driver_arrived`).
  2. التحقق من كود الـ PIN المكون من 4 أرقام من العميل وبدء المشوار (`in_progress`).
  3. إنهاء الرحلة وتحصيل المبلغ وإيداعه في المحفظة (`completed`).
- سجل رحلات الكابتن السابقة وأرباحها اليومية.
- فتح مسار الرحلة مباشرة في خرائط Google Maps للملاحة خطوة بخطوة.

### 3. لوحة الإدارة المركزية (Admin Dashboard):
- حماية أمنية مشددة: التحقق من صلاحيات الإدارة العليا (`isSuperAdmin` أو دور `admin`) قبل تنفيذ أي إجراء إداري حساس.

- إدارة الكباتن: اعتماد السائق الجدد أو إيقاف الحساب.
- إدارة العملاء: حظر أو فك حظر حسابات المستخدمين.
- متابعة حية لجميع الرحلات مع إمكانية الإلغاء الإداري عند الضرورة.
- إدارة الأسعار والعمولات: تعديل فتح العداد، سعر الكيلو، دقيقة الانتظار، السفر خارج العريش، ونسبة عمولة المنصة، مع حفظها فورياً في Firebase.
- عرض الشكاوى والدعم الفني مع زر تحديد الشكوى كمحلولة.
- تصدير تقارير الرحلات المالية والتشغيلية بصيغة Excel / CSV بترميز UTF-8 مع دعم كامل للغة العربية.
