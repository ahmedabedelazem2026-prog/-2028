تطبيق وموقع ويب تقدمي متكامل (**Full Stack Progressive Web Application – PWA**) لشركة **تاكسي العاصمة (كود 1)** في محافظة **شمال سيناء**، بمدينة **العريش** وكافة خطوط السير والجامعات والمحافظات.

---

## 📌 الأنظمة والوحدات المدمجة

يتضمن النظام 4 تطبيقات مترابطة تعمل في منصة واحدة فائقة السرعة ومتوافقة تماماً مع الجوال والحاسوب:

1. **الموقع التعريفي والتسويقي الفاخر**:
   - واجهة مستوحاة من معالم العريش (شاطئ العريش، قلعة العريش، مسجد النصر، جامعة العريش، جامعة سيناء).
   - عرض مميزات الخدمة، فئات السيارات، وأرقام التواصل المباشر وواتساب: `01094129592`.

2. **تطبيق العميل (Customer App)**:
   - خريطة تفاعلية مدعومة بـ **Google Maps JavaScript API** مع محرك احتياطي ذكي (**Leaflet / OpenStreetMap**) لضمان عدم توقف الخريطة أبداً.
   - تحديد نقطة الانطلاق والوجهة بنقرة واحدة على الخريطة أو عبر رقاقات المعالم السريعة.
   - اختيار فئة السيارة (اقتصادي، كمفورت، VIP، عائلي 7 ركاب).
   - حساب فوري ودقيق للمسافة، الوقت المتوقع، وتكلفة المشوار التقديرية.
   - دعم كوبونات الخصم الترويجية (`CAPITAL10`، `ARISH2026`).
   - إرسال طلب الرحلة ومتابعة لحظية لحالة الطلب والكابتن مع زر اتصال مباشر.

3. **تطبيق الكابتن / السائق (Driver App)**:
   - زر التوفر السريع (متاح 🟢 / غير متاح 🔴).
   - استقبال طلبات الرحلات الفورية مصحوبة برنين صوتي تنبيهي (**Web Audio API Dispatch Beep**).
   - **القبول الذري الحصري (Atomic Acceptance)**: أول كابتن يضغط قبول يحصل على الرحلة فوراً ويتم إيقاف الطلب لدى بقية السائقين لمنع التضارب.
   - كارت الرحلة الجارية مع إمكانية فتح المسار مباشرة في **Google Maps Directions**.
   - أزرار التحكم: بدء الرحلة ▶️، وإنهاء الرحلة مع تحصيل الأجرة 🏁.
   - شاشة الأرباح اليومية، عدد الرحلات، ومستحقات الكابتن الصافية.

4. **لوحة الإدارة المركزية (Central Admin Dashboard)**:
   - 10 مؤشرات إحصائية مباشرة (إجمالي الرحلات، الرحلات الجارية، المكتملة، الملغاة، الكباتن، المتصلون، العملاء، الإيرادات، عمولة المنصة 10%، وصافي مستحقات السائقين).
   - جدول الكباتن والسيارات مع خيار الاعتماد الفوري أو الإيقاف.
   - جدول سجل الرحلات المباشر والكامل.
   - محرر نظام الأسعار المرن: تعديل فتح العداد، سعر الكيلو، الحد الأدنى، رسوم الانتظار، ورسوم الرحلات خارج العريش.
   - تصدير تقارير الرحلات بصيغة **Excel / CSV** بنقرة واحدة.

## 🚀 التشغيل والاختبار

### تشغيل خادم التطوير محلياً:
```bash
npm start
# أو عبر الأمر المباشر:
npx serve -l 3000 .
```
ثم افتح في المتصفح: `http://localhost:3000`

### تشغيل حزمة الاختبارات الآلية الشاملة:
```bash
npm test
# أو
node tests/system.test.js
```

## 🌐 النشر على Vercel أو Firebase Hosting

### 1. النشر على Vercel:
المشروع مجهز بملف `vercel.json` الكامل للتوجيه والحماية:
```bash
npx vercel --prod
```

### 2. النشر على Firebase Hosting & Rules:
```bash
firebase deploy --only hosting,firestore:rules,database,storage
```

## 📱 التثبيت كتطبيق PWA
يدعم التطبيق التثبيت المباشر كـ **Progressive Web App** على:
- هواتف **Android**: عبر متصفح Chrome (زر "تثبيت التطبيق" أو القائمة الجانبية).
- هواتف **iPhone (iOS)**: عبر Safari (مشاركة > إضافة إلى الشاشة الرئيسية Add to Home Screen).
- يمتلك ملف `manifest.json` و `sw.js` بكامل الأيقونات والذاكرة المؤقتة.
