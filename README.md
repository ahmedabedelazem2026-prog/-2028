# تاكسي العاصمة

موقع مبدئي لحجز الرحلات في العريش، مع صفحات العميل والسائق والإدارة.

## الملفات الموجودة
- `index.html` و`customer.js`: إنشاء حساب العميل وطلب الرحلة ومتابعة حالتها.
- `driver.html` و`driver.js`: تسجيل دخول السائق، تشغيل/إيقاف التوفر، وعرض الطلبات المعلقة.
- قبول الرحلة يستخدم Firestore transaction حتى لا يقبلها أكثر من سائق في الوقت نفسه.
- `admin.html` و`admin.js`: عرض الحسابات والرحلات وتعديل صلاحية الحساب.
- `firestore.rules`: قواعد مبدئية لحماية بيانات الحسابات والرحلات.
- `firestore.indexes.json`: فهارس الاستعلامات المطلوبة.
- `firebase-config.js`: ملف إعداد Firebase الحالي، وما زالت قيمه تجريبية.

## ما لم يكتمل بعد
- لم يتم ربط المشروع بقاعدة Firebase القديمة؛ بيانات الملف الحالي مجرد placeholders.
- لم يتم إعداد Google Maps أو إضافة مفتاح الخرائط.
- لم يتم نشر قواعد Firestore والفهارس على مشروع Firebase.
- لم يتم اختبار النظام على مشروع فعلي أو ربط رابط الاستضافة.

## خطوات الإكمال
1. إدخال إعدادات Web App من مشروع Firebase الصحيح في `firebase-config.js`.
2. تفعيل Email/Password من Firebase Authentication وإنشاء قاعدة Cloud Firestore.
3. نشر `firestore.rules` و`firestore.indexes.json` على مشروع Firebase.
4. إنشاء حساب الإدارة، ثم تعيين `role: admin` لحسابه من Firebase Console. بعد ذلك يمكن للإدارة تحويل حسابات السائقين إلى `driver`.
5. تجربة حساب عميل وحساب سائق تجريبيين قبل إتاحة الموقع للناس.

**تنبيه:** لا تضع مفاتيح Service Account أو كلمات مرور أو مفاتيح خاصة داخل ملفات الموقع أو المستودع.
