# تاكسي العاصمة

مشروع موقع لحجز الرحلات في العريش.

## الهدف
- العميل يرسل طلب رحلة.
- الطلب يظهر للسائقين المتاحين.
- سائق واحد فقط يستطيع قبول الرحلة.
- لوحة إدارة لمتابعة الطلبات والسائقين.

## حالة التنفيذ
هذه بداية توثيق المشروع فقط. لم يتم ربط Firebase أو Google Maps بعد، ولم يتم نشر نسخة تشغيلية.

## المتطلبات قبل التشغيل
- إعداد Firebase Authentication وCloud Firestore.
- إضافة إعدادات Firebase الخاصة بتطبيق الويب.
- تقييد مفتاح Google Maps على نطاق الموقع وواجهات API المطلوبة.
- اختبار صلاحيات قاعدة البيانات وقبول الرحلات قبل الاستخدام الفعلي.
